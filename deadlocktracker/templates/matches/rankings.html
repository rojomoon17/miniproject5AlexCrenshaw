How the rating works

A plain win rate jumps around on small samples: win your only game on a hero and it shows 100%. The rating fixes that by imagining every hero already has {{ prior_games }} games at your overall win rate ({{ baseline }}% across {{ total_games }} games), then adding your real games on top:

rating = (wins + {{ prior_games }} × {{ baseline }}%) ÷ (games + {{ prior_games }})

  • 1-0 on a hero: ({{ 1 }} + {{ '%.2f'|format(prior_games * baseline / 100) }}) ÷ {{ 1 + prior_games }} = {{ '%.1f'|format(100 * (1 + prior_games * baseline / 100) / (1 + prior_games)) }}%
  • 6-1 on a hero: ({{ 6 }} + {{ '%.2f'|format(prior_games * baseline / 100) }}) ÷ {{ 7 + prior_games }} = {{ '%.1f'|format(100 * (6 + prior_games * baseline / 100) / (7 + prior_games)) }}%

So 6-1 ranks above 1-0, even though 1-0 is a "perfect" record. Lanes and matchups on a hero page use the same idea, starting from your win rate on that hero. The Sample badge shows how much data there is: Low under 3 games, Medium 3-9, High 10+.
